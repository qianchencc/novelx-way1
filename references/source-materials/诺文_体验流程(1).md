# 诺文 · 体验流程

**写给第一次接触诺文的你**

## 开始之前：你需要准备什么

诺文是一款桌面应用（获取与安装方式见提交材料说明）。体验前，请准备三样东西：

**一条打动你的抖音视频。** 三到十分钟为宜，类型不限——一段科幻小说或科幻概念的解说、一部电影或剧集的深度解读、一个历史或神话故事、一条硬核知识科普，都可以。叙事与意象越丰富，种子长出的世界就越丰满。复制它的分享链接，或准备一段本地视频文件即可。诺文提取的是视频中的主题、情绪与意象，目标是生长出属于你的原创世界，而非复刻原作。

**一个本地空文件夹。** 在电脑上新建一个空文件夹（例如命名为"我的科幻世界"），作为项目目录。诺文会把生成的全部世界文件真实写入这个文件夹——它不会替你创建或复制目录，所以请先建好。

**一个可用的模型 API 密钥。** 诺文的生成能力由模型 API 驱动，首次使用需要你亲手填入密钥。【我们提供体验API：模型：XXX；图片：YYY】

以下标注的等待时长均为一般情况下的量级参考，会随内容长度、素材数量与网络环境浮动，供你把握体验节奏。

## 主流程：从一条视频到一个世界（约 3–10 分钟；首次 API 配置另计约 1–2 分钟）

**第 1 步 · 配置 API（仅首次需要）。** 启动诺文，点击左下角的设置，在模型和图片选项里，填入你的 API 密钥，保存。密钥在手的情况下，这一步约 1–2 分钟；此后再次使用无需重复配置。

**第 2 步 · 打开项目。** 点击初始页面中央的「打开项目」（项目列表为空时，该入口显示为「选择已有文件夹」；也可点击左侧项目栏"项目"标题右侧的文件夹图标），在系统文件窗口中选中你刚建好的空文件夹。通常 1–3 秒即可进入；若文件夹内已有较多文件，首次读取约需 5–10 秒。

**第 3 步 · 种下你的种子。** 点击「新会话」（左侧"项目"标题右侧的笔形按钮，或聊天区右上角的同名按钮），会话约 1 秒内出现。在输入框粘贴抖音视频链接——或将视频文件拖入聊天区，看到「松开以添加到对话」提示后松手，视频会作为待发送附件挂在输入框——然后写下你的创作愿望，一并发送。例如：

> "以这条视频为种子，帮我创作一个经典硬科幻世界，并写出其中的第一篇小说。"

**第 4 步 · 与 AI 确认方向。** 发送后立即显示"正在准备回复"，首字通常数秒内出现。诺文会提取视频音频、转写为文字，从中凝练主题与意象，然后向你复述它理解的创作方向并征求确认——因为包含视频处理，这一步的完整回复会比普通问答（约 10–40 秒）稍久一些。你确认方向后，诺文开始在你的项目文件夹中建立世界观、角色、地点、事件与故事结构。

**第 5 步 · 看着世界长出来。** 首批结构文件会在数分钟内陆续出现。最直接的查看方式，是点击对话中出现的文件、图片或链接，它们会直接在工作台中打开；也可以点击最右侧栏的「展开工作台导航」，在右栏顶部点击当前工作台名称（即「切换工作台」入口）选择工作台——中右区域会展开为画布，右栏显示该工作台的文件树。看到第一批世界文件，主线体验就完成了。完整的世界深化生成属于长流程，通常需要十几分钟到几十分钟——你不必等它全部完成，它会在你继续探索时持续生长。

> **快速体验主路径：配置 API（仅首次）→ 打开项目 → 发送视频链接与创作愿望 → 查看陆续生成的世界文件 → 展开工作台查看作品。** 全程约 3–10 分钟。

## 深度体验：成为这个世界的导演（建议预留 1–3 小时）

**继续创作。** 在会话中直接提出要求："写出第一章""为主角生成一张 OC 立绘""画一张世界地图"。短章节约几十秒完成；较长章节或需要 AI 通读项目资料时，约 1–3 分钟。插图提交后即时进入图片队列，单张生成约 30 秒–3 分钟；同一项目内多张插图按顺序依次生成，排队中的会显示「等待生成」。所有作品都会进入项目文件与工作台。

**视觉批注协作。** 在工作台画布中打开一张插图或一页文稿，直接在作品上框选、绘画、添加视觉批注，再交给 AI 按批注修改。这正是诺文核心理念在产品里的样子：AI 做手艺，你做导演。

**建立艺术库。** 让 AI 收集并分类你喜欢的参考图片，提取风格关键词。此后的每一件作品都会延续同一套审美，让整个世界保持统一的个人风格。

**导出项目包。** 完成后，可将整个项目导出为完整的诺文项目包，包含全部作品文件、项目结构、工作台配置与你选择保留的协作案例。这个世界从头到尾都以真实文件的形式存在——它属于你，带走即可。

体验途中，随时可点击画布顶部的「收起工作台」回到纯聊天界面。
